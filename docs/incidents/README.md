# Incident records

This directory holds root-cause-analysis (RCA) documents for security and
safety incidents, as required by the postmortem step of
[`INCIDENT-RESPONSE.md`](../../INCIDENT-RESPONSE.md) and referenced by the
IEC 62443 configuration (`.fusa-iec62443.json`).

Create one Markdown file per incident, named `YYYY-MM-DD-short-slug.md`.
